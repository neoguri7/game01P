# code 레인 기록 (드래프트 1차)

PixelLab 사용 0회. 기준 커밋 832fc7d, 커밋 없음.

## 지시와 다른 점

`ui_layout.json` 의 `bands` 는 0 이 아니라 top 40, bottom 96 이다. `bands` 0 을 복사본에서 돌리면 기준선에서 통과하던
`UiFrameLayout` 이 tests/DungeonTests.cpp 1233 에서 실패했다. 뷰포트가 창 전체가 되면 `topBar` 가 존을 담으면서 뷰포트와
겹치지 않을 수 없으므로 데이터로 풀 수 없다. tests/ 불변이 우선이라 띠를 "그리지 않는 예약 영역"으로 남겼다.
프레임 그림과 띠 그리기 코드는 제거했고 세계는 창 끝까지 그린다. `FUiLayout::arena` 가 존에서 직접 계산되므로
테스트의 1217~1218, 1233~1234 를 고친 뒤 `bands` 만 0 으로 바꾸면 그대로 동작한다 (임시 하네스로 확인).

## 테스트 기준선 (832fc7d, 수정 전 빌드)

- ctest: 5/7. `dungeon_rules`, `ai_behavior` 실패.
- `dungeon_rules`: 라인 256 `AutoActionTokenBoundary`. CHECK 가 throw 하므로 뒤 13개 함수는 ctest 에서 돌지 않는다.
- `ai_behavior`: 라인 1010, 1132, 1348.
- 임시 하네스(out/scratch, tests 복사본, 함수별 try)로 본 결과: 18함수 중 17 통과. 작업 후에도 같은 함수만 실패.
