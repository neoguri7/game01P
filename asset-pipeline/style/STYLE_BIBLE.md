# 스타일 바이블

이 문서가 모든 에셋의 기준이다. 에이전트는 읽기만 한다. 빈칸을 채운 뒤 사용한다.

## 기본
- 장르 / 분위기:
- 뷰 (사이드 / 탑다운 / 아이소):
- 캐릭터 캔버스 (px):
- 타일 크기 (px):
- 픽셀 스케일 (게임 내 확대 배율):

## 선과 면
- 외곽선: (예: 1px, 어두운 갈색 계열 단일색 / 외곽선 없음)
- 셀프 아웃라인 (내부 선) 사용 여부:
- 안티앨리어싱: 사용하지 않음 (알파는 0 또는 255 만)

## 명암과 색
- 광원 방향: (예: 좌상단)
- 색 램프 단계 수: (예: 재질당 3단계)
- 하이라이트 / 그림자 규칙:
- 팔레트: `style/palette.json` 참고

## 비율과 디테일
- 캐릭터 머리 : 몸 비율:
- 디테일 밀도: (예: 얼굴은 눈 2px 만, 장비 질감 표현 안 함)

## 금지
- (예: 그라데이션, 디더링, 반투명 픽셀, 광택 하이라이트)
