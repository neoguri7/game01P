# Game Design Spec — 파밍과 빌드의 재미

Status: **DRAFT (in discussion)**

이 문서는 `PROJECT_VISION.md`가 요구하는 "게임플레이 계약"이다. 여기서 확정된
장르·런 구조·누적 규칙 없이 게임플레이 런타임 코드를 추가하지 않는다.

표기 규칙:

- **확정** — 이미 합의된 결정. 바꾸려면 명시적으로 재논의한다.
- **가정** — 확정은 아니지만 후속 설계가 기대는 전제.
- **미결** — 아직 정하지 않음. 이 항목이 남아 있으면 관련 코드를 쓰지 않는다.

---

## 1. 장르와 핵심 재미

핵심 재미 두 축:

- **파밍** — 변동성 있는 보상과 "다음 판" 기대. 기대값보다 분산과 분해 비용이 중요.
- **빌드** — 제약 안 조합 최적화. 선택지 수보다 시너지 상호작용의 발견이 중요.

두 축의 연결고리(이 게임의 정체성):

- 파밍 = 빌드의 입력 (드롭이 새 선택지를 연다)
- 빌드 = 파밍의 목적 (빌드가 드롭의 가치를 바꾼다)

실패 모드 두 개를 항상 경계한다. (1) 최적 빌드 수렴, (2) 그라인드화.
드롭의 목적은 "파워 상승"이 아니라 "선택지 개방"으로 둔다.

장르 (**확정**): **턴제 그리드 전술 로그라이크**.

- 파티 최대 4명, 전원 직접 조작.
- 캐릭터 부상·사망 없음 (§6.1). 전투에서 쓰러져도 패널티가 누적되지 않는다.
- 그리드(격자) 전장에서 턴제 전투.
- 파티 전멸 = **런 종료 + 진행 초기화**. 남는 것은 명단과 해금 풀뿐이다 (§6).

선택 이유: 스킬 변형 중심 빌드 다양성은 **자주 리셋될 때 가장 맛있다**. 긴 캠페인
RPG는 한 빌드가 오래 고정되어 다양성 재미가 늦게 온다. 그래서 수직 진행은 런 안에만
묶고, 런 사이에는 **옵션(슬롯·변형·풀)**만 누적한다.

빌드 다양성 보존 장치: **변형 슬롯 장착은 비용 없는 자유 교체**다. 스킬/특성 트리
재분배에만 비용을 둔다. 그래야 런마다 로드아웃을 실험하는 재미가 자원에 막히지 않는다.

(번복 기록: 한때 "전멸 시 진행 영속 + 거점 복귀 + 실패한 던전 재도전"을 채택했으나
플레이어 관점 검토 끝에 **폐기**하고 로그라이크로 복귀했다. §9 참조.)

## 2. 런 구조 (**확정**)

1런 = **거점에서 출발해 던전에 연속 진입하는 사이클의 연쇄**. 던전 개수로 끝나지
않는다. 런은 **테마(지역 묶음) 단위로 구간이 나뉘고**, 각 테마 끝에 보스가 있다.

```
거점(hub)
 └ [테마 1] 던전 진입
      ├ 전투(몬스터) 룸
      ├ 이벤트 룸
      ├ 전투 룸
      ├ 전투 룸
      └ 정비(캠프): 강화 또는 교체 1회
   ↺ 다음 던전으로 연속 진입

실패(파티 전멸) → 런 종료 (런 안의 레벨·수치노드·진행 소실, 명단·해금·장비는 잔존)
```

### 진행 체크포인트 (**확정**, 사용자 수정 m00732)

- **진행 단위는 테마가 아니라 던전 1개다.** 첫 기획에서는 단순하게 간다.
- **던전 1개를 클리어하면, 다음 런은 그 다음 던전에서 시작할 수 있다.**
- 클리어하지 못하면 **그 던전을 처음부터 다시** 한다. 되돌아가는 지점은
  **클리어한 던전 개수**다.
- **테마 = 던전 여러 개의 묶음.** 테마는 난이도·분위기 단위이고 진행 단위가 아니다.
  테마의 마지막 던전에 보스가 있다.
- 테마마다 난이도가 점진적으로 오른다.

장비 이월 (**확정 방향**): 던전을 클리어해 다음 던전부터 시작할 때 **장비를 들고 간다**.
이유: 장비가 런 스코프라면 던전 N부터 시작하는 새 런이 맨몸이 되어, 테마별 난이도
상승과 충돌해 진입 자체가 막힌다.

실패 시 잃는 범위: **현재 던전 안에서 얻은 파편·수치노드·룬**. 클리어한 던전까지의
진행도와 장비는 유지된다(장비 영속, 아래).

장비 이월 형태 (**확정 = B, 사용자 결정 m00738**): **장비는 영속이며 획득 장비가 계속
누적된다.** 이유: 상위 던전으로 갈수록 난이도가 오르므로, 강화 요소를 들고 가는 편이
진행 곡선과 맞는다.

- 장비는 **거점 창고에 영속**한다. 런에는 장착 세트를 반입한다.
- 결과: 런 실패 시 영구적으로 잃는 장비는 없다. 손실은 **시간 + 파편 + 수치노드·룬**.

- **던전은 지속 진입한다.** 던전 개수로 런이 끝나지 않는다. 던전 클리어 → 정비 →
  다음 던전 진입을 계속 이어가며, 런 길이는 플레이어가 버티는 만큼 길어진다.
  (사용자 결정, 반복 확인됨: m00666, m00718)
- 정비(캠프) 지점에서 **저장·이어하기 허용** (세션 분할용. 진행을 버리는 "중단"과는 다름).
- 3번째 던전은 중간보스, 테마의 마지막 던전은 진짜 보스.
- 위험·보상은 던전을 거듭할수록 증폭된다. 이어하기가 가능하므로 세션 길이는
  던전 단위(15~30분)로 끊을 수 있다.

### 실패와 재시작 (**확정**)

파티 전멸은 **런 종료**다. 현재 던전 안에서 얻은 **수치노드·룬·파편**은 소실된다.
(런 중에 얻은 장비는 영속이다 — §2.)
남는 것은 §6의 L1/L2/L3, **클리어한 던전까지의 진행도**, 그리고 장비 창고다.

실패의 무게는 "무엇을 잃었는가"가 아니라 "**다음 런에서 무엇이 달라지는가**"에
있다. 전멸 직후 플레이어가 "이번엔 다르게 하겠다"를 즉시 말할 수 있어야 한다.

## 3. 던전과 룸 (**확정**)

던전 1개 = **몬스터 룸 3 + 이벤트 룸 1~2**.

- 초기 기획 단계에서는 개수를 **고정**한다(몬스터 3, 이벤트 1~2). 밸런싱 단계에서
  변동으로 전환 가능.
- 이벤트 룸은 전투 룸 사이에 삽입된다.
- 역할 분담: 몬스터 룸 = 난이도·보상 단조 증가. 이벤트 룸 = 탐험 정체성 담당
  (분기, 숨은 방, 상점, NPC, 단서).
- 숨은 단서 수집은 진짜 보스 출현 트리거 후보다(확률 시드보다 우선 검토).

**가정**: 룸은 데이터 템플릿 풀이다. 런 생성기는 시드로 전투/이벤트 템플릿을 뽑아
배치한다. 따라서 룸 정의는 `assets/data/` 아래 데이터이며 코드가 아니다
(변경 가능성 지침 R17/R22와 정합).

## 4. 전투 (**확정**)

**확정**

- 턴제, 그리드 전장, 파티 최대 4명 직접 조작.
- 목표 전투 길이: 룸당 3~6분. 던전 15~30분.
- **캐릭터 부상·사망 없음.** 쓰러져도 패널티가 누적되지 않는다 (§6.1, 사용자 결정 m00710).
- **턴 자원 = AP 2종 분리** (사용자 결정 m00750, m00756).
  - **이동 AP** — 이동 전용. 잠정값 턴당 **1**(이동 1회).
  - **스킬 AP** — 스킬 전용. 잠정값 턴당 **2**.
  - 두 풀은 **서로 전환되지 않는다**. 이동 AP를 스킬에 쓰거나 그 반대는 불가.
  - 수치(잠정값, 고비용 스킬의 비용 상한)는 밸런싱 단계에서 조정한다.
- **턴 순서 = 속도 기반 이니셔티브 + 순서 예측 표시.** 순서를 숨기면 계획이
  불가능해진다(Grim Dawn 트랜스뮤터와 같은 혼란).
- **그리드 = 8x8.** 사거리는 칸 단위.
- **목표**: 일반 전투 = 적 제거, 보스 = 다단계 목표(부위 파괴 등). 등불 폐기로
  전투 내 보호 목표가 사라졌으므로 목표 다양성은 보스에만 둔다.

**미결 (구현 단계에서 점차 결정 — 사용자 결정 m00756)**

- 이동 AP·스킬 AP의 최종 수치, 고비용 스킬의 비용 상한.
- AP 회복·추가 AP 부여 수단 여부.
- 이동 거리(칸)와 사거리 수치.

## 5. 빌드: 스킬 변형 3층 (**방향 확정 / 수치 미결**)

룬워드식(재료 + 순서 + 미공개 결과)은 직관성이 없다. 필요조건은 **조건은 공개,
결과는 발견**.

### 요소 스코프 (**확정**)

거점에서 정하고 런에 들어가는 것 (영속):

- 캐릭터(명단).
- **각 캐릭터의 해금 스킬 목록** — 스킬 선택은 유저가 거점에서 한다. 빌드의 뼈대는
  파밍이 아니라 플레이어 선택이다.
- **캐릭터 레벨** — 스킬 해금을 담당한다. 소스는 **누적 캐릭터 EXP**(영속).
- **거점 레벨** — 장비 해금을 담당한다.
- **장비 창고** — 장비는 영속이며 계속 누적된다(§2 확정, 사용자 결정 m00738). 런에는
  장착 세트를 반입하고, 런 실패로도 장비를 잃지 않는다.

런 종료 시 초기화되는 것 (런 스코프):

- **런 스코프 캐릭터 EXP** — 런 중에만 쌓인다. 런이 끝나면 소멸한다.
- **수치노드** — **런 스코프 캐릭터 EXP가 포인트를 공급한다**(사용자 결정 m00798).
  런마다 0부터 다시 찍는다.
- **룬** — 스킬 변형 요소. 런 중 드롭으로 얻는다.

경험치 2종 (**확정**, 사용자 결정 m00798):

| 경험치 | 스코프 | 용도 | 런 종료 시 |
| --- | --- | --- | --- |
| 누적 캐릭터 EXP | 영속 | 캐릭터 레벨 → 스킬 해금 | 유지 |
| 런 스코프 캐릭터 EXP | 런 스코프 | 수치노드 포인트 공급 | 소멸 |

런 스코프 EXP 획득 소스 (**확정**, 사용자 결정 m00836): **주 요소는 몬스터 처치**다.
보조 소스(룸 클리어·이벤트)의 채택 여부와 비율은 미정이다. 캐릭터별로 따로 쌓인다.
수치노드도 **캐릭터별 트리**다(사용자 결정 m00836).

레벨 규칙 (**확정**): 레벨은 **스탯을 주지 않는다**. 캐릭터 레벨 = 스킬 해금,
거점 레벨 = 장비 해금. 둘 다 영속 누적 요소다.

누적 EXP 획득 (**확정**): 소스는 **런 결과(던전 클리어, 도달 깊이)**다. 런 실패 시에도
**누적 EXP는 전액 획득**한다. 이유: 전멸 자체가 런 종료로 손실을 이미 발생시키므로,
경험치까지 깎으면 벌점이 중복된다.

스탯 원칙 (**확정**): 스탯 강화는 **장비 + 수치노드**로만 가능하다. 기본 스탯 성장은
두지 않는다(스탯 최소화). 초기 구현 단순화를 위한 결정이다.

파밍의 의도된 비중: 스킬은 거점에서 플레이어가 고르므로, 파밍은 **런의 변수**를
공급한다(장비, 룬). 파밍이 빌드 정체성을 결정하지 않는다.

경고: 수치노드가 순수 배수만 담으면 Path of Exile식 수렴이 일어난다. 노드 총합
배수 상한을 두고, 노드 항목에 **동작 파라미터**(사거리, AP, 쿨다운)를 섞는다.
경계: 룬 = 스킬의 동작 변경, 수치노드 = 수치와 전역 파라미터.

포인트 소스 (**확정, 변경 m00798**): 노드 포인트는 **런 스코프 캐릭터 EXP**가 공급한다.
**"장비가 노드 포인트를 정한다"는 이전 결정은 철회한다.**

- 런마다 0부터 시작하므로 수직 누적이 발생하지 않는다.
- 상한은 런 내 EXP 획득량과 노드 비용 설계로 정해진다(별도 장비 제한 규칙 불필요).
- 이전 가드("장착 장비에서만 포인트 산출")는 폐기한다 — 소스가 런 스코프이므로
  더 이상 필요하지 않다.
- 수치노드는 **런 스코프 캐릭터 EXP**를 쓰므로 **캐릭터별 트리**다.

### 1층 — 변형 슬롯 (직관)

스킬마다 변형 슬롯을 두고, 변형은 **동작만** 바꾼다. 숫자를 키우는 배수 효과는
변형이 아니라 장비가 담당한다. (같은 슬롯에서 경쟁시키면 배수 효과가 항상 이긴다 —
Path of Exile 지원 젬 메타의 교훈)

턴제 그리드에서 "동작 변경"의 범주:

- 사거리/형태 (단일 → 관통 → 장판)
- AP 비용
- 위치 조작 (밀치기, 끌기, 돌진)
- 상태이상 (화상, 감전, 도발)
- 반응/트리거 (카운터, 조건 발동)

직관성 보조: 아이콘 태그 배지, 슬롯 장착 시 결과 미리보기, 조건 미충족 시 비활성
사유 표시.

### 2층 — 태그 상호작용 (공개 규칙)

변형·스킬이 태그를 부여하고, 태그 조합 규칙은 공개한다. 태그가 곧 문법이라
플레이어가 학습할 수 있다 (Last Epoch 방식).

태그 후보(초기 규모 미결): `Projectile / Melee / Fire / Cold / Channel / Summon /
Area / Movement / Duration / Trigger` 정도의 8~12개에서 시작.

### 3층 — 승격 조합 (발견)

특정 변형 2개가 사전조건을 만족할 때만 별도 승격 효과가 후보로 등장한다. 우연
획득(리롤)은 불가. 최초 조합 시 연출 + 도감 해금 (Hades 듀오 보온 방식).

**파티 축 확장**: 파티원 간 태그 조합으로 파티 승격 효과를 둔다
(예: A의 `Fire` + B의 `Projectile`). 파티 4인 구조의 고유 다양성 엔진.

### 변환 파이프라인 순서 (**확정**: 순서를 문서·UI에 명시)

`로컬 스킬 변형 → 장비 전역 변환 → 오라/패시브 배수`

순서를 숨기면 플레이어가 이중 변환을 시도하며 혼란을 겪는다 (Grim Dawn 트랜스뮤터
사례).

## 6. 메타 누적 (런 간 유지) (**확정 골격 / 세부 미결**)

전제 (**확정**): 전멸 시 **대부분 손실**. 초기화 범위는 §5의 요소 스코프를 따른다:
**수치노드, 룬**과 소지 파편은 런 종료 시 소멸한다(장비는 영속 — §2). 런 사이에 남는 것은 아래 층뿐이며,
**수직 스탯 누적은 사용하지 않는다.**

각 층의 공통 기준: 누적은 **정체성과 옵션**을 미리 지불하는 것이지, 파워를 미리
지불하지 않는다.

### L1 — 명단(roster): 정체성 층

남는 것: 이름, 외형, 기질 특성, 관계, 훈장, 해금 스킬 목록, 캐릭터 레벨, 장비 창고.
사라지는 것: 런 스코프 요소(수치노드, 룬)와 런 스코프 캐릭터 EXP.

영구 사망이 없으므로(§6.1) 캐릭터는 명단에서 사라지지 않는다. 부상도 두지 않으므로
캐릭터에는 전투 결과로 인한 수치 패널티가 누적되지 않는다. 명단 상한과 획득
경로가 정체성 확장의 상한이 된다.

**미결**: 명단 상한(제안 12), 상한 초과 시 처리, 새 캐릭터 획득 경로.

### 6.1 손실·긴장 장치 (**확정: 런 자체가 투자 하나만 사용**)

개별 영구 사망을 없앴으므로 "잃는 것"의 축을 정한다. **심플 우선** 원칙에 따라
**후보 1만 채택**한다.

1. **런 자체가 투자 (채택)**: 손실 = 시간(런 길이). Hades·Slay the Spire 방식.
   전제 = 런이 짧고 재시작 마찰이 낮을 것.
2. **회수 가능한 손실(시체 런) — 폐기.** 이유: 전멸 = 런 종료이므로 같은 던전에
   재진입할 수 없다. 회수 메커니즘은 재진입을 전제로 하므로 성립하지 않는다.
   실패 시 소지 파편·미확정 룻은 전부 소실된다.
3. **거시 공용 자원(계정 실패 게이지) — 폐기.** 등불 폐기 결정(§6.2)과 동일 이유.
4. **부상/스트레스 누적 — 폐기.** 캐릭터 부상·사망을 없앤다(사용자 결정 m00710).
5. **세계 위협 진화 — 보류(초기 구현 제외).** 구현 비용이 크고 심플 원칙에 어긋난다.

공통 경고: 무작위성만으로 실패를 만들면 "부당한 난이도"가 된다 — 플레이어 선택에
의한 실패여야 한다.

**미결**: 위 후보 중 채택 조합.

### 6.2 거점 자원 구성 (**확정**)

전제: 거시 자원이 "실패할 때마다 깎이는 카운터"면 그냥 벌점이다. 긴장을 만들려면
**런 안에서 교환 가능한 자원**이어야 한다.

자원을 스코프별로 분리한다.

| 자원(가칭) | 스코프 | 획득 | 사용처 | 런 실패 시 |
| --- | --- | --- | --- | --- |
| 파편 | 런 한정 | 전투·이벤트·아이템 분해 | 정비 강화, 리롤, 초기화권, 치료 | 전부 소실(회수 대상) |
| 인장 | 계정 영구 | 런 성공, 보스 돌파, 도전과제 | L3 풀 해금, 명단 확장, 초기화권 | 해당 없음(성공해야 얻음) |

**등불 폐기 (확정)**: 계정 단위 실패 게이지는 **제거**한다. 이유: 손실이 이미
실재한다 — 전멸 시 런이 종료되면서 런 스코프 요소(수치노드, 룬)와 파편이
전부 사라진다. 별도 게이지를 더하면 벌점이 중복되고, 실패 이유가 "게이지가 닳아서"로
희석된다.

교환 지점(긴장이 실제로 발생하는 위치):

- 정비 지점: 파편을 강화 / 치료 / 초기화권 중 어디에 쓸지.
- 이벤트 룸: "파편 +N 대신 부상 위험" 같은 명시적 교환.
- 경로 선택: 위험한 경로는 보상 트레이드오프를 가진다.

**미결**: 자원 이름, 수치(인장 획득량).

### L2 — 승격(legacy): 옵션 층

내용: 캐릭터별 **스킬 슬롯 +1**, **변형 가능 개수 +1**. 획득 조건은 런 성공
또는 보스 돌파다. 실패한 런은 승격을 주지 않는다.

**경고 (영구 사망 폐기의 부작용)**: 사망이 없으면 승격은 절대 사라지지 않아 런 시작
파워가 무한히 오른다. 상한을 낮게 고정하고(제안 슬롯 5, 변형 4), 상한 도달 후에는
다른 보상으로 전환해야 한다. 안전 기준은 §6의 10~20%p다.

### L3 — 풀 해금: 선택지 층

영구 해금 대상: 새 변형, 장비 베이스, 어픽스, 이벤트 룸, 몬스터, 던전 테마,
클래스, 시작 옵션. 스탯을 팔지 않고 **선택지를 판다**.

**미결**: 해금이 시작 파워를 얼마나 올려도 되는가. 기준: 초기 런의 바닥 파워를
올리는 해금(예: 시작 아이템)는 최소화하고, 옵션 폭을 늘리는 해금을 주력으로 둔다.

### 누적 금지 목록 (**확정**)

다음은 모두 실패의 무게를 죽이므로 누적하지 않는다:

- 영구 스탯 % / 영구 시작 레벨
- 골드·장비 이월
- 영구 부활 또는 사망 무효화
- 런 시작 시 전회 런의 빌드 자동 복원

### 재편(리스펙) 절충 (**확정 방향**)

- **변형 슬롯 장착/해제**: 비용 없는 자유 교체. 런 준비 단계에서 실험한다.
- **스킬·특성 트리 재분배**: 런 시작 시 자유. **런 중 재분배**는 초기화권을 소비한다.
- **장비 교체**: 자유.

근거: 무료 리스펙(Diablo 3)은 실험을 장려하지만 캐릭터 정체성을 약화시키고,
고비용 리스펙(Path of Exile의 Regret Orb)은 룻 가치를 올리지만 "잘못 찍으면
캐릭터가 망한다"는 공포로 외부 빌드 가이드 의존을 만든다. 그래서 뼈대 재편은
유한 자원으로, 세부(변형 장착·장비)는 무료로 둔다.

**미결**: 초기화권 획득 경로(파밍 드롭 / 이벤트 룸 / 보스 보상)와 희소도.

### L4 — 거점 시설: **제외**

L1/L2/L3가 시작 조건을 바꾸므로 별도 시설 층을 두지 않는다. 거점은 기능(정비,
편성, 창고)을 제공하는 장소이지 별도의 누적 성장 층이 아니다.

### 지켜야 할 규칙

- **UI 표시**: 영구 vs 런 한정을 명확히 구분한다. (Wildermyth는 "일시 디버프가
  유산 영웅을 영구 변경하는가"에 대한 커뮤니티 혼동이 있었다)
- **죽음의 착지점**: 죽은 캐릭터는 묘지/기념비에 남는다. 손실을 0으로 만들지 않고
  기록으로만 남긴다.
- **재시작 마찰**: 전멸 후 다음 런 첫 전투까지 2분 이내(로딩·편성·정비 포함).
- **수직 누적 안전 기준**: 1번째 런과 20번째 런의 승률 차가 10~20%p 이내.
  주의: 여기에는 플레이어 실력 성장이 섞인다. 승률만 보지 말고 "같은 실력
  구간에서의 시작 파워"를 별도로 측정한다.

## 7. 파밍 (**방향 확정 / 수치 미결**)

- 드롭 3계층: trash(즉시 분해) / 어픽스 롤(부분 무작위) / 유니크(고정 아이덴티티 =
  빌드 정의).
- 중복 드롭은 재료로 환금(분해 → 리롤)해 분산을 줄인다.
- 나쁜 운 보정: pity 또는 결정론적 재료 누적.
- 파밍의 대가는 위험한 장소다. 순수 노가다를 금지한다.
- 목표: 정비 지점마다 빌드 진화 1회 → 한 런에서 여러 번 빌드가 바뀐다.

**미결**: 드롭 소스별 기대값, 어픽스 풀 크기·티어, 리롤 비용, 이벤트 룸 종류 목록.

## 9. 결정 이력

- 3던전=1런 가정 → **폐기**. 1런 = 던전 연속 진입 사이클의 연쇄.
- 자발적 중단(획득 확정) 가정 → **폐기**. 종료는 파티 전멸뿐이며, 정비 지점의
  저장은 "이어하기"용이다.
- 런 종료 지점을 던전 개수로 고정하는 안 → **폐기**.
- 거점 시설(L4) 누적 층 → **폐기**. L1/L2가 시작 조건을 바꾼다.
- "전멸 시 레벨·장비 초기화, 수직 누적 없음" 방침 → **폐기**(1차). 이유: 플레이어 관점에서
  전면 초기화는 투자 감각을 파괴한다.
- "전멸 시 진행 영속 + 거점 복귀 + 실패한 던전부터 재도전 + 초기화권 리스펙" 방침
  → **폐기**(2차, 사용자 번복). 이유: 빌드 다양성 재미는 자주 리셋될 때 가장 크다.
  **로그라이크(전멸 = 런 종료 + 진행 초기화)로 복귀.**
- 장르 표기 "턴제 그리드 파티 던전 크롤러" → **"턴제 그리드 전술 로그라이크"로 복귀**.
- 단, 2차 검토에서 살아남은 것: 리스펙 절충(D3/PoE 근거), 변형 슬롯 자유 교체,
  재시작 마찰 2분 기준, 수직 안전 기준. 이들은 §6에 유지했다.
- "L2 승격은 캐릭터 귀속 + 사망 시 소실" 안 → **폐기**. 사망 자체를 없앴으므로 성립하지 않는다.
- 개별 영구 사망 자체 → **폐기**. 런 중 쓰러져도 런 종료 후 캐릭터는 영구 소실되지
  않는다. 대체 손실 장치는 §6.1에서 분석 중.
- 강화 요소의 스코프 확정(§5): **영속 = 캐릭터 + 해금 스킬 목록 + 캐릭터 레벨 +
  거점 레벨**, **런 종료 시 초기화 = 장비 + 수치노드 + 룬**. 스탯은 장비와 수치노드로만
  강화하고 기본 스탯 성장은 두지 않는다. 이유: 스킬 선택을 플레이어가 거점에서 하므로
  파밍이 빌드를 결정하는 비중이 적절해지고, 초기 구현이 단순해진다.
- 레벨 역할 확정: 레벨은 스탯을 주지 않는다. **캐릭터 레벨 = 스킬 해금,
  거점 레벨 = 장비 해금.**
- 장비 영속 안 → **폐기**. 이유: 초반 던전이 너무 쉬워진다. **장비는 런 스코프.**
- 룬 획득 시점 확정: **런 중 드롭**, 런 스코프.
- 노드 포인트 소스: **런 스코프 캐릭터 EXP**가 공급한다(변경 m00798).
  ~~장착 장비에서만 포인트 산출(슬롯 고정)~~ 가드 → **폐기**(m00798).
  ~~"장비가 노드 포인트를 정한다"~~ 결정 → **철회**(m00798).
  이유: 포인트 소스가 런 스코프면 런마다 0부터 시작해 수직 누적이 사라지므로,
  장비를 포인트 소스로 삼을 이유가 없다. 수치노드는 캐릭터별 트리다.
- 레벨 경험치 **확정**: 경험치는 2종이다. **누적 캐릭터 EXP**(영속 → 캐릭터 레벨 →
  스킬 해금)와 **런 스코프 캐릭터 EXP**(런 스코프 → 수치노드 포인트 공급).
  누적 EXP 소스는 런 결과(던전 클리어·도달 깊이)며, 런 실패에도 전액 획득한다.
  이유: 전멸이 이미 런 종료로 손실을 만든다.
- **등불 시스템 제거** (§6.2). 이유: 손실이 이미 실재(런 종료 = 장비·수치노드·룬·
  파편 소실)하므로 계정 게이지는 벌점 중복이고, 실패 원인을 게이지 소진으로 희석한다.
- **캐릭터 부상·사망 제거** (§6.1, §6 L1). 이유: 사용자 결정 m00710 — 심플 우선.
  따라서 손실·긴장 장치는 **"런 자체가 투자"(후보 1)만 채택**한다. 시체 런(후보 2)은
  전멸 = 런 종료라 재진입이 없어 성립하지 않아 폐기, 거시 실패 게이지(후보 3)는
  등불 폐기와 함께 폐기, 부상 누적(후보 4)은 폐기, 세계 위협 진화(후보 5)는
  보류(초기 구현 제외).
- **테마 진행 도입** (§2), 이후 **대수정 m00732**: 진행 체크포인트 단위는 테마가
  아니라 **던전 1개**. 던전 클리어 = 다음 런에서 그 다음 던전 시작 가능, 실패 = 그
  던전 처음부터. 테마 = 던전 여러 개 묶음(난이도 단위), 마지막 던전에 보스.
  이유: 런을 끝내지 않고 되돌아갈 지점을 전진시키므로 "전멸만이 종료" 미결과
  "인장 지급 지점이 없다" 문제가 풀린다.
- **장비 이월 형태 = B(완전 영속)** (§2, 사용자 결정 m00738). 이유: 상위 던전일수록
  난이도가 오르므로 강화 요소를 들고 가는 편이 진행 곡선과 맞는다. 결과: 런 실패 시
  영구적으로 잃는 장비는 없고, 손실은 시간 + 파편 + 수치노드·룬으로 한정된다.
- **턴 자원 = AP 2종 분리** (§4, 사용자 결정 m00756): 이동 AP(이동 전용)와
  스킬 AP(스킬 전용)를 각각 따로 둔다. 서로 전환 불가. 잠정값 이동 AP 1, 스킬 AP 2.
- 장비 영속의 부작용 가드는 **폐기**(m00798): 노드 포인트 소스가 런 스코프 캐릭터
  EXP로 바뀌면서 불필요해졌다.
