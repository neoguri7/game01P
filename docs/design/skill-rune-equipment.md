# 스킬 · 룬 · 장비 시스템 (개편안)

Status: **DRAFT (확정 골격 / 잠정수치)** — 작성: 2026-10-06.

이 문서는 `docs/design/game-design.md` §5(빌드 3층)와 §7(파밍)의 **스킬·룬·장비 부분을
대체**한다. `docs/design/stage6-plan-prompt.md`의 어픽스/레어리티/유니크 계획은 **폐기**한다.

표기 규칙은 `game-design.md`와 동일하다: **확정 / 가정 / 미결**. 아래 `미결`이 하나라도
남아 있으면 관련 런타임 코드를 확정 구현하지 않는다(데이터 + `// 미결` 스텁만).

---

## 1. 확정 골격

전투에 영향을 주는 빌드 요소를 다음 3가지로 단순화한다.

- **베이스 스킬** — 캐릭터가 보유한 스킬. 무속성. 거점에서 로드아웃 선택.
- **룬** — 스킬에 **여러 개** 장착. 속성 / 형태 / 강화의 3축. **런 스코프**.
- **장비** — 스탯만 제공. 직업 구분 없음. **+N 강화**로 수치 상승. **영속**(창고 누적).

폐기:
- 어픽스 롤 / 레어리티(normal·magic·rare·unique) / 유니크 / 접사 티어.
- "스킬당 변형 슬롯 1개" 제한.
- 전투 영향 **수치노드**와 **경험치(EXP)** 계열은 이번 범위에서 **제외**한다(추가 가능성 있음).
  → `game-design.md` §5의 수치노드 서술은 이 개편 범위에서 보류 상태이며, 부활 시 별도 결정.

## 2. 베이스 스킬

무속성 7종. 속성은 룬이 부여한다. **`파이어볼`은 폐기** — "원거리 볼트 + 화염 룬"으로 표현한다.

| id | 이름 | 범주 | 잠정 형태 | 설명 |
| --- | --- | --- | --- | --- |
| `skill.strike` | 강타 | 공격 | 단일(근접) | 인접 1칸 대상 강타 |
| `skill.arrow` | 에로우 | 공격 | 단일(원거리) | 원거리 단일 사격 |
| `skill.bolt` | 볼트 | 공격 | 단일(원거리) | 원거리 마법 탄. 화염룬의 기반 |
| `skill.heal` | 힐 | 지원 | 단일(아군) | 아군 HP 회복 |
| `skill.fog` | 안개 | 지원 | 장판(지속) | 지역에 지속 상태 부여(명중/이동 저하 등). 세부 미결 |
| `skill.buff` | 버프 | 지원 | 단일/자신 | 아군 강화 상태 부여 |
| `skill.debuff` | 디버프 | 지원 | 단일(적) | 적 약화 상태 부여 |

- 스킬은 `id, display_name, ap_cost, power, range, shape, area_radius, tags, status`를 데이터로 가진다.
- `shape`는 룬의 **형태 룬이 덮어쓸 수 있다**(§3.2).

## 3. 룬

룬은 스킬에 장착되어 스킬을 변형한다. 스킬당 **여러 개** 장착 가능하며, 축별 규칙은 아래와 같다.

### 3.1 속성 룬 (최대 2개)

- 예: `화염`, `냉기`, `전기`, `독`, `신성`, `암흑`.
- **실제 전투 계산에 영향을 준다 — 상태이상을 부여한다.** (§4)
- 한 스킬에 서로 다른 속성 룬을 **최대 2개**까지 장착 가능(중복 장착 불가).
- 속성 룬 자체는 수치 배율을 주지 않는다. 상태이상만 부여한다.

### 3.2 형태 룬 (최대 1개)

스킬의 **동작(형태)을 바꾼다**. 최대 1개만 장착(택1).

| id | 이름 | 동작 |
| --- | --- | --- |
| `form.spread` | 확산 | 단일 → 대상 인접 칸으로 공격이 퍼진다 |
| `form.pierce` | 관통 | 단일 → 직선상의 적들을 관통 |
| `form.zone` | 장판 | 단일 → 지속 지역(장판)으로 전환 |

- 형태 룬은 수치를 키우지 않는다(동작만). 단, `areaRadius`/`range` 등 형태 파라미터는 데이터.

### 3.3 강화 룬 (고유 강화만, 중복 금지)

- 스킬의 수치를 강화한다: 데미지, AP cost, 사거리, 상태 지속 등.
- **같은 강화 룬은 중복 장착 불가**(고유 강화만). 즉 상한은 "정의된 강화 룬 종류 수"다.
- 초기 강화 룬 세트(잠정, `assets/data/rune.json`): `위력`(power +), `절약`(ap_cost −1, 최소 1),
  `사거리`(range +1), `지속`(부여 상태 지속 +1), `범위`(area_radius +1), `정밀`(치명 확률 +).
- **배수 수렴 방지**(`game-design.md` §5 경고 대응): 강화 룬은 고유 1개씩이고,
  스킬의 총 수치 증가(데미지 계열)에 **상한**을 둔다(잠정: 기본 대비 +100%). 상한 초과분은 무시.

### 3.4 룬 자체 강화

- 룬은 레벨을 가진다(잠정 **1..3**).
- 강화 효과: 수치 룬 → 수치 상승, 형태/속성 룬 → 지속시간/범위 상승.
- 재화: **파편**(런 스코프). 잠정 비용: L1→L2 = 2 파편, L2→L3 = 4 파편.
- **룬과 룬 강화는 런 스코프다.** 전멸 시 소실된다(`game-design.md` §2/§5의 룬 스코프 유지).
- **미결**: 상한(3 vs 5), 재화 비용, 강화 실패/하락 여부.

## 4. 상태이상

**확정**: 상태이상은 실제 전투에 적용된다. 중첩 규칙 = **갱신**(재부여 시 지속시간 리셋, 강도는 최신값).

구현 모델(가정): `FActiveStatuses { std::vector<FStatusEffect> }`,
`FStatusEffect { id, turnsRemaining, magnitude }`. 기존 계획의 `FSkillTag`/`FActiveTags`를
이 구조로 **일반화**한다. 틱 시점 = **해당 유닛의 자기 턴 시작**(기존 태그 틱과 동일 지점).

| id | 이름 | 효과 | 잠정 |
| --- | --- | --- | --- |
| `status.burn` | 화상 | 자기 턴 시작 시 `magnitude` 피해 | 지속 3턴 |
| `status.freeze` | 빙결 | 이동 불가 + 속도 저하 | 다음 2턴, 속도 ×0.5 |
| `status.paralyze` | 마비 | 턴 시작 시 확률적 행동 불가 | 2턴, 확률 50% |
| `status.buff` | 버프 | 스탯/AP 증감(양) | 데이터 |
| `status.debuff` | 디버프 | 스탯/AP 증감(음) | 데이터 |

- 부여 경로: 속성 룬(화상/빙결/마비 등) + `안개`/`버프`/`디버프` 베이스 스킬.

**미결**: 상태별 최종 수치(화상 magnitude, 마비 확률), 상태 면역/저항, `안개`의 구체 효과.

## 5. 장비

### 5.1 원칙

- **직업 구분 없음.** 장비는 슬롯/스탯 종류로만 구분된다.
- 제공: **스탯만**. 스킬이나 상태를 바꾸지 않는다(그건 룬 계층).
- **영속**: 거점 창고에 누적되고 런에는 장착 세트를 반입한다(전멸로 장비를 잃지 않음).

### 5.2 슬롯 (가정)

무기 / 보조 / 신발 3슬롯 유지(잠정). 직업 제한은 없고, 슬롯 제한만 둔다.
**미결**: 슬롯 수·종류를 이대로 둘지, 자유 장착으로 바꿀지.

### 5.3 스탯 (가정)

`공격력`, `최대 체력`, `이동 AP`, `스킬 AP`, `사거리` (잠정). 최소·최대 클램프를 둔다.

### 5.4 장비 강화 = 아이템 전역 +N

**확정**: 강화는 **아이템 전역 +N**이다. 스탯별 개별 강화가 아니다.

- 잠정식: 강화된 스탯 = `floor(base * (1 + 0.1 * N))` (N레벨, 레벨당 +10%).
- 재화: **파편**(런 스코프). **미결**: 강화 상한, 비용 곡선, 실패/하락 여부.
- 강화는 장비(영속)에 붙으므로 **영속**된다.

**주의(F3)**: 장비가 영속·누적이고 이제 +N 강화까지 붙으므로 "시작 파워"가 계속 오른다.
`game-design.md` §6의 수직 안전 기준(1번째 런 vs 20번째 런 승률 차 10~20%p)을 지키려면
장비 누적 상한 장치가 필요하다. **미결**: 상한을 (a) 장비 티어 곡선, (b) 슬롯/장착 제한,
(c) 강화 상한 중 무엇으로 둘지.

## 6. 계산 파이프라인 (개정)

`game-design.md` §5의 파이프라인에서 노드 층을 제거한다.

```
베이스 스킬 + 룬(속성/형태/강화)   →   장비 전역(+N 강화)   →   최종 수치
```

- 1단계: 베이스 스킬을 룬이 변형(형태 덮어쓰기, 강화 수치, 상태 부여).
- 2단계: 장비 스탯과 +N 강화를 합산.
- 노드/오라 층은 이번 범위에서 제외.
- **미결**: 최종 피해 공식(`game-design.md` G5). 잠정 `max(1, attack + power)` 유지.

## 7. 드롭 (개정 — 구 3계층 폐기)

- 드롭 대상: **장비**, **룬**, **파편**.
- 잠정 룸당 비율: 장비 55% / 룬 30% / 파편 15%.
- 장비 드롭 → 거점 창고 누적(영속). 룬 드롭 → 런 스코프 인벤토리. 파편 → 런 스코프.
- **미결**: 던전 깊이별 룬/장비 티어, 중복 룬의 분해 환금.
