# 스킬 · 룬 · 런 성장 시스템 (개편 3차)

Status: **DRAFT (확정 골격 / 잠정수치)** — 작성: 2026-10-06 (3차 개편).
2차 개편(장비 폐기·런 스코프 성장)을 유지하고 **스탯·클래스·룬 제한 모델**을 개정한다.
파일명은 2차 개편의 `skill-rune-progression.md`를 유지한다.

이 문서는 `docs/design/game-design.md` §5(빌드)·§7(파밍)의 **스킬·룬·성장 부분을 대체**한다.
`stage6-plan-prompt.md`의 어픽스/레어리티/유니크 계획은 **폐기**(1차와 동일).

표기 규칙은 `game-design.md`와 동일하다: **확정 / 가정 / 미결**. 아래 `미결`이 하나라도
남아 있으면 관련 런타임 코드를 확정 구현하지 않는다(데이터 + `// 미결` 스텁만).

## 0. 3차 개편 요약 (사용자 결정 2026-10-06)

- **캐릭터 기본 스탯 확정**: `hp`, `공격력`, `마법공격력`, `속도`, `방어력`, `마법방어력`.
- **클래스 기본 3종**: 전사, 궁수, 법사.
- **스킬·룬은 PoE를 더 직접적으로 모방**한다: 스킬 = 공격(무기)/주문(마법) 분류 + 태그,
  룬 = 서포트젬(소켓에 장착).
- **룬 축(속성/형태/강화) 폐기**: 축별 상한 대신 **스킬별 룬 소켓 수**가 제한을 담당한다.
  2차의 태그 엄격 규칙(§3.2)과 중복 금지는 유지한다.

## 1. 확정 골격

전투에 영향을 주는 요소는 4가지다.

- **베이스 스킬(장착)** — 클래스별 풀에서 장착. 캐릭터별 스킬 슬롯(잠정 4). §2.
- **룬(서포트)** — 스킬의 **룬 소켓**에 장착. 태그 규칙이 장착 조건을 결정. **런 스코프**. §3.
- **강화 물질** — 룸 클리어 보상. 정비 지점에서 **스탯 강화**에 소비. **런 스코프**. §5.
- **런 EXP → 레벨 → 노드** — 단순화된 PoE식 트리. **런마다 0부터**. §6.

### 1.1 스탯 (**확정**)

| 스탯 | 역할 | 비고 |
| --- | --- | --- |
| `hp` | 최대 체력 | FHealth.max |
| `공격력` | 물리 피해의 공격 항 | Attack 스킬 |
| `마법공격력` | 마법 피해의 공격 항, 힐 회복량 | Spell 스킬 |
| `속도` | 이니셔티브(턴 순서) | design §4 |
| `방어력` | 물리 피해 감소 | 피격 시 |
| `마법방어력` | 마법 피해 감소 | 피격 시 |

- 피해 공식 (**잠정**): `max(1, offense + power − defense)`.
  - `offense` = 공격력(물리) / 마법공격력(마법), `defense` = 방어력(물리) / 마법방어력(마법).
  - 최종 공식 확정 전까지 이 함수 하나만 고친다(수치 하드코딩 금지).
- 힐 회복량 (**잠정**): `마법공격력 + power`.
- 스탯 강화는 **노드 + 강화 물질**로만 가능하다(기본 성장 없음, 2차 유지). 둘 다 런 스코프.

### 1.2 클래스 (**확정: 3종**)

| 클래스 | 성격 | 스킬 축 | 기본 스탯(잠정) |
| --- | --- | --- | --- |
| 전사 | 근접 물리 | Attack·Melee | hp 140 / 공격 8 / 마법공격 2 / 속도 4 / 방어 5 / 마법방어 3 |
| 궁수 | 원거리 물리 | Attack·Bow | hp 100 / 공격 6 / 마법공격 3 / 속도 7 / 방어 3 / 마법방어 3 |
| 법사 | 주문 | Spell | hp 90 / 공격 2 / 마법공격 8 / 속도 5 / 방어 2 / 마법방어 5 |

- 클래스 = **기본 스탯 + 시작 스킬 풀**(잠정: `units.json`에 직접 저작).
- 클래스 하드 게이트(스킬 장착 제한)는 두지 않는다 — 장착 가능 목록은 해금이 담당(미결).
- 적 유닛도 같은 스탯 체계를 쓴다(클래스는 비워 둘 수 있다).

## 2. 베이스 스킬

- 스킬은 `id, display_name, ap_cost, power, range, shape, area_radius, target,
  applies_status, tags, damage_type, rune_sockets`를 데이터로 가진다.
- `damage_type`: `physical` | `magical`. 공격(Attack)은 물리, 주문(Spell)은 마법으로 저작한다.
- `rune_sockets`: 이 스킬에 장착 가능한 룬 수(잠정 **3**).
- `shape`는 룬의 형태 변경 룬이 덮어쓸 수 있다(§3).
- **태그 초기 세트**: `Attack`, `Spell`, `Melee`, `Bow`, `Projectile`, `AoE`, `Duration`,
  `Curse`, `Heal`, `Support`, `Zone`(장판 형태가 부여). (`Movement`, `Minion`은 예약 — 이번 범위 제외.)
- **스킬 슬롯 4**(잠정, 캐릭터별). 거점/정비에서 자유 교체.
- **스킬 해금 경로(미결)**: 영속 EXP 폐기(2차)로 공백. 후보 = 인장(L3), 드롭, 이벤트.
  이번 구현은 **저작 로드아웃**(데이터)으로 진행한다.

로스터 (잠정 9종):

| id | 이름 | 클래스 | 태그 | damage_type | 잠정 형태 |
| --- | --- | --- | --- | --- | --- |
| `skill.strike` | 강타 | 전사 | `Attack`, `Melee` | physical | 단일(근접) |
| `skill.cleave` | 회전베기 | 전사 | `Attack`, `Melee`, `AoE` | physical | 확산(대상+인접) |
| `skill.arrow` | 에로우 | 궁수 | `Attack`, `Bow`, `Projectile` | physical | 단일(원거리) |
| `skill.volley` | 연사 | 궁수 | `Attack`, `Bow`, `Projectile` | physical | 확산(대상+인접) |
| `skill.bolt` | 볼트 | 법사 | `Spell`, `Projectile` | magical | 단일(원거리) |
| `skill.fog` | 안개 | 법사 | `Spell`, `AoE`, `Duration`, `Zone` | magical | 장판(지속) |
| `skill.heal` | 힐 | 법사 | `Spell`, `Heal` | magical | 단일(아군) |

| `skill.debuff` | 디버프 | 법사 | `Spell`, `Curse`, `Support` | magical | 단일(적) |

- `파이어볼`은 여전히 폐기 — "볼트 + 화염 룬"으로 표현한다.
- `안개`의 구체 효과는 미결(§4).

## 3. 룬 (서포트젬)

### 3.1 제한 (3차: 축 폐기)

- **룬 소켓**: 스킬마다 `rune_sockets`(잠정 3)개까지 장착. **소켓 수가 유일한 수량 제한**이다.
- **중복 금지**: 같은 룬을 한 스킬에 두 번 장착할 수 없다(PoE와 동일).
- **태그 엄격**(2차 유지): 미충족 룬은 장착 불가.
- L2 승격 = **소켓 +1**(잠정, 캐릭터별. 미구현 — game-design §6).
- ~~속성 ≤2 / 형태 ≤1 / 강화 고유~~: **폐기**(3차). 축 개념 자체를 없앤다.

### 3.2 태그 규칙 (**확정**, 2차 유지)

룬은 태그 요구/부여 데이터를 가진다: `requires_all_tags`, `requires_any_tags`,
`excludes_tags`, `adds_tags`.

- 장착 검증은 **고정점**으로 한다. `T = 베이스 스킬 태그 ∪ (장착된 모든 룬의 adds_tags)`
  일 때, 모든 룬이 `requires_all ⊆ T`, `requires_any ∩ T ≠ ∅`, `excludes ∩ T = ∅`를
  만족해야 한다.
- **순서 무관**: 장착 순서가 결과를 바꾸지 않는다.
- 미충족 룬은 **장착 불가**(로드아웃 검증 실패). UI는 미충족 사유를 표시한다.
- **태그 연쇄가 빌드 퍼즐**: 요소 룬이 속성 태그를 부여해야 그 속성을 요구하는 강화 룬이 열린다.

### 3.4 소유와 드롭 (가정)

- 룬은 **런 스코프 인벤토리**. 같은 룬을 여러 개 소유할 수 있다(여러 스킬에 각각 장착).
- 장착은 소유 수량에서 차감, 해제 시 반환.
- **미결**: 중복 룬 분해(→강화 물질 환금) 여부·비율.

## 4. 상태이상

**확정**: 상태이상은 실제 전투에 적용된다. 중첩 규칙 = **갱신**(재부여 시 지속시간은 긴 쪽
유지, 강도는 최신값). 틱 시점 = **해당 유닛의 자기 턴 시작**.

| id | 이름 | 효과 | 잠정 |
| --- | --- | --- | --- |
| `status.burn` | 화상 | 자기 턴 시작 시 `magnitude` 피해 | 지속 3턴 |
| `status.freeze` | 빙결 | 행동 불가 + 속도 저하 | 다음 2턴, 속도 ×0.5 |
| `status.paralyze` | 마비 | 턴 시작 시 확률적 행동 불가 | 2턴, 확률 50% |
| `status.buff` | 버프 | 공격 항 증가(물리/마법 공용) | 데이터 |
| `status.debuff` | 디버프 | 공격 항 감소(물리/마법 공용) | 데이터 |

- 부여 경로: 요소 룬(화상/빙결/마비) + `안개`/`버프`/`디버프` 스킬.
- 보정 룬: 지속(전체 +1), 연소(화상 피해 +), 혹한(빙결 지속 +), 감전(마비 확률 +).
- **미결**: 상태별 최종 수치, 저항/면역, `안개`의 구체 효과, 빙결 속도 저하의 적용 시점
  (잠정: 다음 라운드 스냅샷부터 — 전투 완성 슬라이스에서 구현).

## 5. 강화 물질과 스탯 강화 (2차 유지, 항목 개정)

- **강화 물질**: 몬스터 룸 클리어 보상. **런 스코프**. 전멸 시 소실.
- **소비**: 정비 지점(캠프)에서 **캐릭터 스탯 강화**. 항목별 비용·상한은 데이터.
- 잠정 강화 항목(3차 스탯 기준): `공격력 +1`, `마법공격력 +1`, `방어력 +1`,
  `마법방어력 +1`, `최대 체력 +5`, `속도 +1`(상한 낮게).
- 구 **파편은 강화 물질로 통합**(가정). 인장(계정 영구, 해금용)은 유지.
- **영속 스탯 강화 없음**: 물질·강화 모두 런 스코프다.

## 6. 런 성장: EXP · 레벨 · 노드 (2차 유지, 효과 개정)

- **런 스코프 캐릭터 EXP** 단일. 획득: 몬스터 처치(주 요소). 캐릭터별로 따로 쌓인다.
- 레벨업 임계값 = 데이터(잠정: 레벨 L→L+1에 `10 + 5×(L−1)` EXP). 레벨업마다 **노드 포인트 +1**.
- **노드 트리 (단순화 PoE)**: 캐릭터별, 런마다 0부터. 인접 노드만 할당. 노드당 1포인트.
  - 효과(3차 스탯 기준): 공격력·마법공격력·방어력·마법방어력·최대 체력·속도·사거리·
    상태 지속/피해 등 + 소수 노터블(동작 파라미터). **총 배수 상한**을 둔다.
  - 이번 구현(가정): **공용 트리 1개 템플릿**을 모든 캐릭터가 공유(각자 할당).
- 할당 UI(미결): 정비 지점 패널(잠정).

---

## 7. 드롭 (2차 유지)

- 드롭 대상: **룬**, **강화 물질**.
- 잠정: 몬스터 룸 클리어마다 물질 `3~5` + 룬 `40%` 확률 1개. 깊이 스케일은 미결.
- 룬·물질·EXP 모두 **런 스코프**. 전멸 시 소실.

---

## 8. 계산 파이프라인

```
베이스 스킬 + 룬(태그·형태·강화·상태)   →   런 성장(노드 + 물질 스탯)   →   최종 수치
```

- 1단계: 베이스 스킬을 룬이 변형(형태 덮어쓰기, 강화 수치, 상태 부여/보정, 흡혈).
- 2단계: 노드·물질 스탯(`hp·공격력·마법공격력·속도·방어력·마법방어력`)을 합산.
- 피해: `max(1, offense + power − defense)` (잠정). 힐: `마법공격력 + power` (잠정).
- **미결**: 최종 피해 공식 확정(G5).
