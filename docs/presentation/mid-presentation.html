02확정된 게임 프레임

전투

  • 턴제 · 그리드 8×8 · 사거리 = 칸
  • 파티 최대 4 · 전원 직접 조작
  • AP 2종 분리 — 이동 1 / 스킬 2
  • 속도 기반 이니셔티브

런

  • 단위 = 던전 1개 (테마 = 난이도 묶음)
  • 던전 = 몬스터 룸 3 + 이벤트 룸 1–2
  • 룸 시작 시 파티 온전
  • 전멸 = 런 종료

누적

  • 영속: 명단 · 승격 · 풀 해금 · 장비 창고
  • 런 한정: 수치노드 · 룬 · 파편
  • 스탯 강화 = 장비 + 수치노드뿐

06슬라이스 2 — 텍스트 전투 코어

sequenceDiagram

  participant T as 턴 루프
  participant M as 몬스터
  P->>T: 이동 / 스킬 선택

07슬라이스 3 — 던전 런 상태 기계

stateDiagram-v2

규칙

  • 다음 던전 = 클리어 수 % 던전 목록 → 끝나면 순환
  • 룸 시작 = 파티 온전 (HP/AP 리셋)
  • 시드 고정 → 같은 시드 같은 런

실패의 무게

  • 전멸해도 클리어 수는 남는다
  • 되돌아가는 지점은 던전 처음 하나뿐
